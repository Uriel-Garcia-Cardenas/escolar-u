Programación III. Programación Visual

Objetivo general

El alumno podrá realizar programas de alta calidad utilizando diversas técnicas para desarrollar elementos visuales y eventos de comunicación con el entorno del usuario.

Contenido temático

  • Unidad 1: Introducción a la construcción de interfaces (conceptos de ventanas, iconos, menús, botones, cajas de diálogo, eventos, transferencia de archivos, diseño funcional).
  • Unidad 2: Diseño de interfaces con lenguajes de programación (creación de interfaces simples, menús y cajas de diálogo).
  • Unidad 3: Manejo de figuras e imágenes (dibujado de figuras geométricas básicas, manejo de imágenes vectoriales).

Bibliografía básica

  • Ceballos Sierra, Javier, Visual C++ : aplicaciones para Win32, Impr. Alfaomega : Ra-Ma, 2004.
  • Godse A.P., Computer Graphics, 2da. Edición Impr. Technical Publications Pune. 2007.
  • Newark, Q., What Is Graphic Design?, RotoVision SA 2007.
  • Sheneiderman, B., Designing the user interface: strategies for effective human-computer interaction, Impr. Addison-Wesley, 1993.
